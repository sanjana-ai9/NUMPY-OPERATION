# Day 12: NumPy Array Operations

## Description
This project demonstrates basic mathematical operations using NumPy arrays in Python.

## Objective
To understand NumPy arrays and perform basic numerical operations.

## Tools Used
- Python
- NumPy
- Jupyter Notebook

## Operations Performed
- Created two NumPy arrays.
- Performed addition and subtraction.
- Performed multiplication and division.
- Found the maximum and minimum values.
- Calculated the sum and mean.
- Calculated the square of each element.

## Learning Outcome
Through this task, I learned how to create NumPy arrays and perform mathematical operations on numerical data. I also understood how NumPy makes calculations easier.

## Conclusion
This task helped me improve my understanding of NumPy and its use in basic data analysis.
